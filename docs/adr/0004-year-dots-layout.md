# ADR 0004: Year Dots layout geometry

Status: accepted (2026-10-14)

## Context
Spec 5.10B defines the continuous grid exactly but leaves the Months packing loose. The layout runs in Dart (app), Kotlin (live wallpaper) and possibly Swift, so every constant must be fixed.

## Decision
Inputs: `N` days, area `W × H`, gap ratio `g = 0.3`, aspect `a = 0.8` (w/h). Gaps are `g·w` in both directions.

**Continuous:** for `c = 10..31`, `rows = ceil(N / c)`,
`w = min(W / (c + (c-1)g), H / (rows + (rows-1)g) · a)`. The largest `w` wins; ties (within 1e-9) keep the smaller `c`. The grid is centred. Day `i` (0-based) sits at column `i % c`, row `i ~/ c`.

**Months:** each month block has 7 columns and 7 rows: row 0 is the month-initial label, rows 1-6 are weeks. Weeks start on **Monday**, independent of locale, so every renderer agrees. Day `d` of a month whose first day has ISO weekday `k` sits at index `(k - 1) + (d - 1)`, column `index % 7`, row `1 + index ~/ 7`. Blocks are separated by one cell width `w`.
For an arrangement of `bc × br` blocks:
`w = min(W / (bc(7 + 6g) + (bc - 1)), H / (br(7/a + 6g) + (br - 1)))`.
Arrangements tried: 3×4 then 4×3; the larger `w` wins (ties keep 3×4). Month `m` (0-based) is in block column `m % bc`, block row `m ~/ bc`. The whole arrangement is centred.

## Consequences
`shared-test-vectors/year_dots/layout_test_vectors.json` is generated by an independent Python implementation (`generate.py` beside it). The Dart and Kotlin renderers must both reproduce it within 0.01 px.
